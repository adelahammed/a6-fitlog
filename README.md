# Fitlog

A simple workout management website that helps users organize and maintain their daily workout plans.

## Technologies

* Next.js
* React
* Tailwind CSS
* DaisyUI
* React Toastify
* Vercel

## Features

* 🏋️ Workout Library
* 📋 Workout Details
* 📅 Daily Workout Plan
* 🔖 Saved Workouts
* 📊 Saved & Today's Workout Summary
* 🔔 Toast Notifications
